华夏历 Huaxia Li — Parametric Calendar Experiments

本地修订预览，尚未发布。华夏历以日月合参、节候与并行周期组织时间，探索参数化历法结构。

Huaxia Li explores solar–lunar relations, seasonal markers and parallel cycles. Defined output is not proof of universal astronomical applicability. These tools are experiments, not certified civil calendars.

  • Parameter classification and candidate satellite demonstrations, with explicit assumptions.
  • Complete-month event counts distinguish empty months, net counts and multi-event compensation.
  • Solar-year windows and day-boundary comparisons expose scope and event-ownership differences.

Published papers remain unchanged; corrections are additive. Historical rules, source-table checks and browser acceptance remain incomplete.
